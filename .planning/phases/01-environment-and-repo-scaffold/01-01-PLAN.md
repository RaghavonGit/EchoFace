Pin rationale (do NOT change):
- tiktoken==0.5.2: tiktoken 0.6+ lacks Python 3.8 wheels in some builds; openai-whisper pulls tiktoken, so pin immediately after
- clip @ git+...: PyPI "clip" is an unrelated package; GitHub URL is the only correct CLIP install
- librosa==0.9.2: 0.10+ requires scipy>=1.7.3 but base env pins scipy==1.7.1; failure is silent at import, only surfaces in runtime calls
- gradio>=3.40,<4.0: Gradio 4.x uses Python 3.10+ syntax (match statements); pip may install a py3-tagged wheel that passes install but crashes at import
- numpy<1.24: numpy 1.24 removed np.bool/np.int/np.float aliases used in StyleGAN-Human internals; install last after all other deps
- pytorch-fid>=0.2.1: 0.2.x series is compatible with PyTorch 1.9.x
