  <behavior>
    generate_fn(mic_audio, file_audio, text_input, wrapper, cfg) — generator function:
    - Empty input guard: if not prompt and audio_path is None → yield ("Please provide a description or record audio.", "", None, None, gr.update(visible=False)) then return
    - Text bypass: if text_input.strip() is non-empty → skip all ASR; use text directly
    - ASR path: if text empty and audio provided → call process_audio(audio_path) then Transcriber(cfg).transcribe(array); if word_count < 3, append " [WARNING: very short transcription — consider editing]" to status
    - File upload takes precedence: audio_path = file_audio if file_audio is not None else mic_audio
    - Optimization: use queue.Queue + threading.Thread to call optimize() so callback can put items into queue; generator loop reads from queue and yields score updates per step
    - Sentinel: optimize thread puts None into queue when done (finally block)
    - Exception: if 'err' in result_holder → yield (f"Generation failed: {err}", "", None, None, gr.update(visible=False)) then return
    - Final yield: ("Done.", f"CLIP similarity: {final_sim:.4f}", np.array(pil_image), pil_image, gr.update(visible=True))
      — note: 4th element is PIL.Image for gr.State; 3rd element is numpy for gr.Image display

    export_image(pil_image, outputs_dir) — regular function:
    - If pil_image is None → return (gr.update(visible=False), gr.update(value="No image to export"))
    - timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    - path = os.path.join(outputs_dir, f"{timestamp}.png")
    - pil_image.save(path)
    - return (gr.update(visible=True), gr.update(visible=True, value=path))
    - Export_image takes outputs_dir as a parameter (not hardcoded) so tests can use tempfile.mkdtemp()

    The threading pattern for live score updates (from RESEARCH.md Pattern 2):
    ```python
    score_q = queue.Queue()
    result_holder = {}

    def _cb(step, loss, sim_score):
        score_q.put((step, sim_score))

    def _run():
        try:
            result_holder['ok'] = optimize(prompt, wrapper, cfg, callback=_cb)
        except Exception as exc:
            result_holder['err'] = exc
        finally:
            score_q.put(None)  # sentinel

    t = threading.Thread(target=_run, daemon=True)
    t.start()

    while True:
        item = score_q.get()
        if item is None:
            break
        step, sim = item
        yield (f"Optimizing... step {step}/150", f"CLIP similarity: {sim:.4f}", None, None, gr.update(visible=False))
    ```

    Correct structure:
    ```python
    def _build_demo(wrapper, cfg):
        import functools
        gen = functools.partial(generate_fn, wrapper=wrapper, cfg=cfg)
        exp = functools.partial(export_image)

        with gr.Blocks(title="EchoFace") as demo:
            # ... layout ...
            gen_btn.click(fn=gen, inputs=[mic_in, file_in, text_in],
                          outputs=[status_out, score_out, image_out, stored_image, export_btn])
            export_btn.click(fn=exp, inputs=[stored_image],
                             outputs=[export_btn, export_path])
        return demo

    if __name__ == "__main__":
        cfg = gpu_utils.get_device_config()
        PKL_PATH = os.path.join(PROJECT_ROOT, "StyleGAN-Human", "pretrained_models", "stylegan_human_v2_1024.pkl")
    ```
